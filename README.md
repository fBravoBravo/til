# Today I Learned (TIL)

> A daily log of technical discoveries, gotchas, and lessons learned while building cloud-native systems at scale.

## Philosophy

Every day I touch infrastructure, code, or tooling I learn something worth writing down. This repo is that running notebook — condensed, searchable, and public.

## Structure

```
├── aws/              # AWS services, patterns, and gotchas
├── terraform/        # Infrastructure-as-Code lessons
├── messaging/        # Event-driven and async patterns
├── nodejs/           # TypeScript / JavaScript / runtime
├── python/           # Python patterns, FastAPI, etc.
├── ai/               # LLMs, agentic workflows, codegen
├── cicd/             # Pipelines, GitHub Actions, quality gates
├── observability/    # Logs, metrics, traces, alerting
└── README.md         # You are here
```

## Contributing

These are personal notes. If something here helps you or you spot an error, feel free to open an issue.
